# Renesas MCU Embedded Software Offer overview

Renesas empowers developers to achieve design success by providing a comprehensive suite of professional development tools and embedded software components. This ecosystem helps you differentiate your product, accelerate design cycles, and reduce costs.

This repository offers a concise overview of the Renesas embedded software available for Renesas microcontrollers, along with links to the relevant repositories.

> [!NOTE]
> A separate repository, **Renesas_MPU_Overall_Offer**, covers the Renesas MPU offer (RZ family) on GitHub.

For a broader understanding of the Renesas MCU ecosystem and its tools, please refer to [Getting Started with the Renesas Flexible Software Package (FSP)](https://renesas.github.io/fsp/).

On Renesas' GitHub organization, you will find repositories covering most of the **Renesas MCU Embedded Software**. These resources are also accessible via [www.renesas.com](https://www.renesas.com), the **e² studio** IDE, and the **RA Smart Configurator (RASC)**.

Beyond the all-in-one repositories, which include example projects for popular Renesas Development Kits like the **EK-RA**, **FPB-RA**, and **Renesas Starter Kit (RSK)** evaluation boards, the platform provides modular repositories for specific components and packs, such as:

- The **CMSIS** interfaces, offering access to the Arm Cortex®-M processor core features and device-specific peripherals of Renesas RA microcontrollers,
- The **Flexible Software Package (FSP)** Hardware Abstraction Layer (HAL) ensuring maximum portability across the RA portfolio, complemented by the low-level register-access APIs — a lightweight, expert-oriented layer closer to the hardware. Both HAL and register-level APIs can be used together with minimal restrictions,
- **Board Support Packages (BSP)** for additional hardware found on the promotion boards (e.g., external memories, audio codecs, graphics/display controllers),
- **Middleware** including RTOS (Azure RTOS/ThreadX, FreeRTOS, Zephyr), USB, file systems, capacitive touch sensing, and secure bootloader,
- **Utilities** including standard output redirection and basic task scheduling for bare-metal applications.

These repositories also empower Renesas developers to **report issues and contribute updates**, facilitated by a Contributor License Agreement feature (see each repository's CONTRIBUTING guide).

> [!NOTE]
> For broader support or non-software-related inquiries, please visit the [Renesas Engineering Community](https://community.renesas.com/) or the [Renesas Support Center](https://www.renesas.com/support).

The Renesas Hardware Abstraction Layer is delivered through the **Flexible Software Package (FSP)** for the RA family, and through **peripheral driver-based software** (Smart Configurator components, code generators, and driver packages) for the RX and RL78 families. Depending on your Renesas MCU family, we recommend starting with the appropriate introduction page as outlined in the tables below.
